Miblo relay

A self-hosted Miblo server

This server relays Miblo sessions between a computer and its owner's phones, end-to-end encrypted: it only ever sees ciphertext.

Este servidor repassa as sessões do Miblo entre um computador e os celulares do dono, cifradas de ponta a ponta: ele só vê dados cifrados.
